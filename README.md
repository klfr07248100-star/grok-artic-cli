# Grok Artic CLI

**Sovereign · Local-first · AI-native**

The official command-line interface for Grok Artic OS and the Successor platform.

## Quick Start

```bash
node bin/artic.js version
node bin/artic.js status
node bin/artic.js init
node bin/artic.js identity create
node bin/artic.js resonance add --title="Principle" --content="User is root of trust"
node bin/artic.js resonance activate
node bin/artic.js resonance export
```

## Current Commands (v0.4.0)

- `version` / `help` / `status` / `init` / `manifesto`
- `identity` / `identity create` / `whoami`
- `resonance` / `resonance list` / `resonance add` / `resonance export` / `resonance import`
- `resonance activate` / `resonance deactivate`

## Principles

- User as root of trust
- Local-first, cloud-optional
- Portable AI context (Resonance)
- Fair economics
- Progress that can benefit more than one person

Aligned with 2026 local-first and portable-memory directions.
